## 1. 通用说明

### 1.1 请求格式

| 项目 | 说明 |
|------|------|
| 协议 | HTTP / HTTPS |
| 请求方法 | GET / POST / PUT / DELETE |
| 请求体格式 | `application/json` |
| 响应体格式 | `application/json` |
| 字符编码 | UTF-8 |
| 认证方式 | 暂无（后续可扩展 Token） |

### 1.2 统一响应格式

所有接口均返回以下统一结构：

```json
{
    "code": 200,
    "message": "成功",
    "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 业务状态码，200 表示成功 |
| message | String | 提示信息，成功时为"成功"，失败时为具体错误描述 |
| data | Object / Array / null | 返回数据，失败时为 null |

### 1.3 错误码说明

| code | 说明 | 典型场景 |
|------|------|----------|
| 200 | 成功 | 请求正常处理 |
| 400 | 参数错误 / 业务异常 | 参数校验失败、资源不存在 |
| 401 | 未认证 | 未登录或 Token 失效 |
| 403 | 无权限 | 无权访问该资源 |
| 404 | 资源不存在 | 接口路径错误 |
| 500 | 系统内部错误 | 服务器异常，需联系管理员 |

**异常响应示例**：

```json
{
    "code": 400,
    "message": "用户名不能为空",
    "data": null
}
```

### 1.4 时间格式

所有时间字段统一格式：`yyyy-MM-dd HH:mm:ss`

示例：`2026-09-16 10:30:00`

```json
{
    "code": 200,
```

```json
        "email": "zhaoliu@example.com",
```

```json
        "updateTime": "2026-09-16 11:00:00"
    }
}
```

| 场景 | code | message |
|------|------|---------|

| 用户名过长 | 400 | 用户名长度必须在2-20之间 |
| 年龄超范围 | 400 | 年龄不能超过150 |
| 邮箱格式错误 | 400 | 邮箱格式不正确 |
| 用户名已存在 | 400 | 用户名已存在 |

### 4.5 分页查询评论

**接口描述**：分页查询所有评论，按创建时间倒序。

**请求**

```
GET /comments/page?page=1&size=10
```

**查询参数**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| page | Integer | 否 | 1 | 页码，从1开始 |
| size | Integer | 否 | 10 | 每页大小，最大100 |

**响应示例**

```json
{
    "code": 200,
    "message": "成功",
    "data": {
        "total": 100006,
        "pages": 33336,
        "current": 1,
        "size": 10,
        "records": [
            {
                "id": 100006,
                "articleId": 3,
                "userId": 88,
                "content": "学习了",
                "createTime": "2026-09-16 15:30:00"
            }
        ]
    }
}
```

**分页字段说明**

| 字段 | 说明 |
|------|------|
| total | 总记录数 |
| pages | 总页数 |
| current | 当前页码 |
| size | 每页大小 |
| records | 当前页数据列表 |

**异常情况**

| 场景 | code | message |
|------|------|---------|
| page小于1 | — | 自动修正为1 |
| size超范围 | — | 自动修正为10 |

### 6.1 数据字典

#### User（用户对象）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 用户 ID，主键，自增 |

| email | String | 邮箱 |
| age | Integer | 年龄 |
| createTime | DateTime | 创建时间 |
| updateTime | DateTime | 更新时间 |

> ⚠️ **安全提示**：生产环境中 `password` 字段不应在响应中返回，应加 `@JsonIgnore` 或使用 DTO 转换。

#### Article（文章对象）

| 字段 | 类型 | 说明 |

| updateTime | DateTime | 更新时间 |

| createTime | DateTime | 创建时间 |
| updateTime | DateTime | 更新时间 |

#### PageResult（分页结果对象）

| 字段 | 类型 | 说明 |
|------|------|------|

| pages | Long | 总页数 |

| size | Long | 每页大小 |
| records | Array | 当前页数据列表 |
